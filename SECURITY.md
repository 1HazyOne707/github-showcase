# Security Policy

This is a personal showcase/learning repository, not production software --
but if you find a genuine security issue (e.g. a workflow with an exposed
secret, an injection vector in a script), please report it responsibly.

## Reporting

Open a GitHub issue with minimal public detail, or contact the repository
owner directly via GitHub, and I'll follow up to get more information
privately if needed.

## Supported Versions

This repository does not follow a formal versioning/support-window scheme --
only the latest state of `main` is maintained.
