# Contributing

This started as a personal learning project -- a place to build real GitHub
workflows (Actions, Pages, automation) rather than just read about them.

That said, if something here is useful or broken and you'd like to fix it:

1. Open an issue describing what you'd change and why.
2. Fork the repo and create a branch off `main`.
3. Keep changes focused -- one logical change per pull request.
4. Open a PR referencing the issue.

No formal CLA or heavyweight process -- this is a small repo and I'd rather
keep contributing to it simple.
